Q) I will write a paragraph for each methodology of SDLC. There are many of them, but I will suggest a few. My suggestions and reasons are as follows:

A) Waterfall Methodology:

It's best for projects with well-defined requirements and minimal changes.

B) Agile Methodology:

Agile focuses on iterative development, flexibility, and customer collaboration.

C) V-Model Methodology:

It emphasizes early testing and validation, ensuring quality from the start.

Q) Among so many SDLC methodologies, the ones that are in the Agile classification are better. Among Agile SDLC Methods, I have also a few suggestions.

A) Scrum:

Scrum is an Agile framework that divides the development process into small, iterative cycles known as sprints.

B) Kanban:

It helps to improve efficiency by limiting work-in-progress and ensuring tasks are completed before starting new ones.

C) XP (Extreme Programming):

XP focuses on improving software quality through frequent releases in short development cycles.

Q) What are the different ways to include CSS in a webpage and how does each method work?

A) Inline CSS:

Inline CSS applies styles directly to HTML elements using the style attribute. It's used for quick styling of a single element.

B) Internal CSS:

It allows styling of multiple elements on a single page.

C) External CSS:

External CSS is written in a separate .css file. This is the best method for large websites, as it allows the same style sheet to be used across multiple pages:

Q) The reasons CSS is used in a webpage are:

A) Separation of Concerns:

CSS allows the separation of content (HTML) from design (CSS). This makes the webpage more flexible, easier to maintain.

B) Improved Website Performance:

By using external CSS files, browsers cache the styles, which improves the load time and reduces the overall size of the webpage.

C) Easier to Apply Consistent Styles:

CSS provides a way to apply consistent styles across a webpage or multiple pages.

Q) We also use JavaScript in webpage development. The main reasons are as follows:

A) Interactivity:

JavaScript allows developers to create dynamic and interactive websites. For example, interactive forms, buttons, and live updates can be achieved with JavaScript.

B) Enhances User Experience:

With JavaScript, you can create animations, drag-and-drop features, and real-time updates that significantly improve the user experience.

C) Asynchronous Loading:

JavaScript enables asynchronous programming through AJAX (Asynchronous JavaScript and XML), which allows data to be loaded dynamically without reloading the page. This improves website performance and user experience.

D) Cross-Platform Compatibility:

JavaScript works across various platforms and browsers, ensuring that web applications function consistently across different devices and browsers.

E) Server-Side Development:

JavaScript is not limited to the browser. With the help of frameworks like Node.js, JavaScript can also be used for server-side programming, allowing for full-stack development.
